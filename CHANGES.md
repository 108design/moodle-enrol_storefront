# Storefront Enrolment 1.0.0

Link a Storefront product to one course or to several courses. Set the Moodle
role and access duration for each mapping. The plugin grants access after
Storefront confirms payment and links the order to the buyer's account.

Course backups retain a disabled product hint for manual reassignment after
restore. Purchased enrolments stay with the original course.

Requires Moodle 4.5 or later and a compatible 108design Storefront release.
